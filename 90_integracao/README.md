# Integração final

Esta pasta reúne índices, checklists e cópias finais. Caio não altera os artefatos recebidos. Se uma correção for necessária, o arquivo retorna ao autor e uma nova versão substitui a anterior.

As passagens entre autores são verificadas conforme `../00_governanca_caio/protocolo_comunicacao.md`. Caio não integra um artefato consumido por outro cargo enquanto o marco obrigatório estiver sem versão, teste ou confirmação do destinatário.

## Ordem do pacote

1. `relatorio/`
2. `mvp/`
3. `modelagem/`
4. `dashboard/`
5. `apresentacao/`
6. `materiais/`
7. `governanca/`

## Regra de congelamento

O manifesto registra nome, versão, autor, data e hash ou commit. Depois do congelamento, qualquer alteração cria uma nova versão e exige novo ensaio de 20 minutos quando afetar conteúdo, fórmula, interface ou sequência da apresentação.

Uma alteração também exige `ALTERAÇÃO COM IMPACTO`, nova confirmação de todos os consumidores indicados e atualização dos hashes. A versão operacional só recebe `PACOTE FINAL INTEGRADO` quando não houver passagem pendente.
